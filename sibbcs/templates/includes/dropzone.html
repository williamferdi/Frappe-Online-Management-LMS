{# Drag and drop for file inputs, shared by /apply and /documents. Progressive, not a replacement: the real stays in the page, invisible but present, so the browser's own picker, the keyboard and a screen reader all keep working. Dropping a file sets `input.files` through a DataTransfer and dispatches `change`, so every page's existing upload code runs unchanged and none of it has to know this include exists. Any element with class="dropzone" wrapping a file input is upgraded. #}
