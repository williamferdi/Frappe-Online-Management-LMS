{# Shrink a photographed document before it is uploaded. Shared by /apply and /documents, both of which post files as base64 inside a JSON body. Why this exists. That base64 body is a third larger than the file itself, and nginx gives a stalled request body sixty seconds before it closes the connection with a 408. A four-megabyte phone photo of a mark sheet, going up a mobile uplink, does not reliably make it. That is exactly how APP-2026-00014 lost every document it attached -- twice -- while the page sat on "Uploading documents..." for four minutes a file with nothing on screen moving. A mark sheet is perfectly legible at 2000px on its long edge. Re-encoding one at that size turns four megabytes into a few hundred kilobytes, which goes up in seconds and never meets the timeout at all. Four rules keep this from ever costing a candidate their document: * A PDF is never touched. It is already compressed and cannot be re-encoded in a canvas. * A file already under LEAVE_ALONE_BYTES goes exactly as it is. Re-encoding a small, sharp scan only makes it blurrier for no gain. * If the re-encoded copy is not actually smaller, the original is sent. * If anything at all fails -- an image the canvas cannot decode, a browser without `toBlob`, a tainted canvas -- the original is sent. This step may degrade an upload's size; it may never lose the upload. The camera's own rotation is applied while drawing (`imageOrientation: 'from-image'`), so a mark sheet photographed in portrait does not arrive on its side. Frappe strips EXIF when it saves an image and does not rotate first, so for anything that comes through here that orientation is now baked into the pixels rather than discarded with the metadata. Exposes one function: sibbcsPrepareUpload(file) -> Promise<{content, filename, content_type, bytes, original_bytes}> `content` is base64 without the data-URL prefix, which is what `uploads.upload_document` takes. `filename` and `content_type` move together when a PNG is re-encoded as JPEG -- the server checks the extension, the declared type and the magic bytes against each other, so a re-encoded file that kept its old name would be refused. #}
